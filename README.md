# Librería Web

Portal web desarrollado con PHP, MySQL, HTML, CSS, JavaScript y Bootstrap.

## Funcionalidades

- Listado de libros
- Listado de autores
- Búsqueda de autores
- Formulario de contacto
- Almacenamiento de mensajes en MySQL mediante PDO

## Tecnologías

- PHP
- MySQL
- PDO
- HTML5
- CSS3
- JavaScript
- Bootstrap

## Base de datos

El script se encuentra en `database/libreria.sql`.
